# KTU S1 SGPA Calculator 🎓

## 📌 Project Overview

The **KTU S1 SGPA Calculator** is a Python-based desktop application developed to help first-semester engineering students under APJ Abdul Kalam Technological University (KTU) calculate their Semester Grade Point Average (SGPA) easily and accurately.

The application provides a simple and user-friendly graphical interface where students can select the grades they received in each subject. By clicking the **Get SGPA** button, the calculator automatically calculates and displays the corresponding SGPA using the credit-weighted calculation method.

The main objective of this project is to simplify SGPA calculation and eliminate the need for manual calculations.

## ✨ Features

- **User-Friendly Interface:** Simple and interactive graphical user interface.
- **Grade Selection:** Dropdown menus for selecting grades in each subject.
- **Automatic SGPA Calculation:** Calculates SGPA based on the selected grades and corresponding subject credits.
- **Seven Subjects:** Supports all seven subjects in the KTU first-semester engineering curriculum.
- **Instant Results:** Displays the calculated SGPA immediately after clicking the Get SGPA button.
- **Grade Options:** Supports S, A+, A, B+, B, C+, C, D, P and F grades.

## 🛠️ Technologies Used

### 1. Python

Python is the primary programming language used to develop this application. It handles the calculation logic, grade point conversion, user input processing, and SGPA computation.

### 2. Tkinter

Tkinter is Python's standard GUI (Graphical User Interface) library. It is used to create the application's graphical interface and make it interactive.

Some of the Tkinter features and widgets used include:

- **Labels:** To display subject names, instructions, headings, and SGPA results.
- **Dropdown Menus (Comboboxes):** To allow users to select their grades for individual subjects.
- **Buttons:** To trigger the SGPA calculation when clicked.
- **Frames:** To organize and group different GUI components.
- **Layout Management:** To arrange and position widgets within the application window.

## 🚀 How to Use

1. Launch the application.
2. Select the grade received for each of the seven subjects using the dropdown menus.
3. Click the **Get SGPA** button.
4. The calculated SGPA will be displayed on the screen.

## 💻 How to Run the Project

### Prerequisites

- Python 3.x installed on your system.
- Tkinter installed (usually included with standard Python installations).

### Steps to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/shonjoseph196/sgpa_calculator.git
   ```

2. Navigate to the project directory:

   ```bash
   cd sgpa_calculator
   ```

3. Run the Python file:

   ```bash
   python main.py
   ```
